# Design Deck

A premium web/app design starter and reference hub for building polished product interfaces.

## Core stack

- Next.js + TypeScript
- Tailwind CSS
- shadcn/ui-compatible component structure
- Motion for micro-interactions
- Premium glass / editorial / product UI primitives
- Reference workflow for Mobbin, Land-book, Refero, SaaSFrame, Awwwards, Behance
- Component-source workflow for Aceternity UI, Magic UI, React Bits, 21st.dev

## Goal

Use this repository as the reusable design foundation for high-end web apps, product UIs, landing pages, research tools, dashboards, and Apple-like interfaces.
