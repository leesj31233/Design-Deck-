# Archetype benchmark set

Design Deck uses benchmark products as **principle sources, not screens to clone**. The goal is to understand why a strong interface works, then express those ideas in Design Deck's own tokens and components.

## Knowledge / research workspace

### Obsidian
- Graph View: https://obsidian.md/help/plugins/graph
- Canvas: https://obsidian.md/canvas
- Extract: note relationships, backlinks, spatial thinking, dense local workspace, low visual fatigue.
- Do not copy: exact shell, icons, command layout or proprietary product identity.

### Raycast
- Design principles: https://www.raycast.com/blog/a-fresh-look-and-feel
- Extract: fast/simple/delightful, keyboard-first actions, visible shortcuts, disciplined icon language.

## Engineering / operations

### Grafana
- Dashboards: https://grafana.com/grafana/dashboards/
- Dashboard design guidance: https://grafana.com/blog/getting-started-with-grafana-best-practices-to-design-your-first-dashboard/
- Extract: purpose-first panels, status hierarchy, trends and diagnostics, operator scanning.

### Palantir Foundry / Slate
- Slate overview: https://www.palantir.com/docs/foundry/slate/overview
- Extract: operational applications, configurable workflows, data + actions in one surface, complex system navigation.

## Editorial / photography

### Awwwards
- https://www.awwwards.com/
- Extract: typography, composition, pacing, interaction restraint, image-led storytelling. Treat award galleries as discovery, not as a component source.

### Behance editorial / photography work
- https://www.behance.net/
- Extract: art direction, contact-sheet rhythm, case-study pacing, editorial hierarchy.

### Magnum Photos / magazine references
- Use established photography and editorial publications to study image sequencing, captions, whitespace and archive navigation. Use only licensed/original imagery in production.

## Motion / interactive components

### Motion Primitives
- https://motion-primitives.com/
- Extract: reusable Motion + Tailwind micro-interactions suitable for real interfaces.

### Rive
- https://rive.app/use-cases/websites
- Extract: stateful animated icons, toggles, loaders, hero interactions and data-storytelling motion. Use Rive where vector state machines justify the runtime; use Motion/CSS for ordinary UI state.

### Aceternity / Magic UI / React Bits / 21st.dev
- Keep these as selective source layers for project-specific visual moments.
- Never import an entire effects catalogue into a productivity surface.

## Selection rule

A pattern enters the shared Design Deck core only if it is reusable across products, accessible, explainable, and visually coherent without the original reference brand. Experimental visuals stay in the archetype or project layer.
