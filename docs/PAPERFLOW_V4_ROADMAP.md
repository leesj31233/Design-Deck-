## 1. 번역 비용 구조와 최적화

**비용이 생기는 곳**(gpt-4.1-mini, 100만 토큰당 입력 $0.40 · 캐시 입력 $0.10 · 출력 $1.60)
- **출력(한국어 번역문):** 비용의 약 70%를 차지한다. 원문 영어 토큰의 약 1.1~1.2배이고, 번역 품질을 유지하는 한 줄일 수 없다.
- **입력:**
  - 문단 원문이 약 절반이다.
  - 나머지 절반은 요청마다 반복되는 지시문(용어 정책, 형식 규칙, 응답 스키마)이었다.

**적용한 것**(측정: 최근 1시간 안에 번역하지 않은 논문)
- **고정 앞부분 캐시:** 지시문과 스키마를 모든 요청과 사용자에게 바이트 단위로 동일하게 만들었다. 용어집은 입력으로 옮기고, ID 목록은 p0~p15로 고정하고, `prompt_cache_key`를 지정했다. 1,280토큰이 캐시 단가(1/4)로 계산된다.
- **묶음 크기:** 6문단·4,200자에서 16문단·9,000자로 키웠다. 첫 묶음은 3,000자로 두어 첫 표시 속도를 유지하고, 이 묶음을 먼저 보내 캐시를 예열한다.
- **결과:**
  - Applied Energy: $0.0325 → $0.0282
  - Bioresource Technology: $0.0289 → $0.0252
  - 두 편 모두 **약 −13%**, 시간 같음, 실패 0
- **공유 번역 캐시:** 같은 원문 문단은 사용자 전체에서 한 번만 번역한다. 두 번째 독자부터는 그 논문의 번역 비용이 0원이고, 즉시 표시된다. 인기 논문이 많을수록 사용자당 비용이 크게 떨어진다.

**검토 후 채택하지 않은 것**
- **gpt-4o-mini(약 2.7배 저렴):**
  - 오역이 있었다: injector → 분무기, burnout zone → 탈연소 구역, negative correlation → 부정적인 상관관계.
  - 한국어에 영어가 섞였다("화염 공 near에서").
  - 방침을 위반했다: Figure → 그림, methane → 메탄.
  - 재시도가 3배 많았다.
- **gpt-4.1-nano(약 4배 저렴):** 원문에 없는 문장과 인과관계를 지어냈다.
- **Batch API(50% 할인):** 결과가 최대 24시간 뒤에 나온다. 그래서 즉시 번역에는 맞지 않는다. 대량 보관용 "나중에 번역" 옵션으로는 후보로 남긴다.
